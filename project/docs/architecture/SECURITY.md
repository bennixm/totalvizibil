# Security

## Principles

- Least privilege
- Secure authentication
- Secure payment processing
- No storage of raw card details
- Audit logs
- Role-based access control
- API authorization
- Input validation

## AI Security

AI agents must not have unrestricted access to financial operations.

AI-generated actions should pass through validated backend APIs.

## Payments

Payment card data should be handled by the payment provider.

The platform should store references and transaction information rather than raw payment credentials.
