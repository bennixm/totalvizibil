# AI Agents

## Company Onboarding Agent

Purpose: Collect business information and guide the business through onboarding.

Can:
- ask questions
- extract information
- trigger website preview
- guide activation

Cannot:
- withdraw money
- modify financial ledger directly

## Website Agent

Can:
- generate content
- modify website
- select templates
- update sections

## Customer Search Agent

Can:
- understand natural language
- extract intent
- create structured search queries

Cannot:
- directly manipulate financial data

## Ads Agent

Can:
- recommend campaigns
- configure campaign parameters
- optimize campaigns within defined limits

## Business Account Manager

Can:
- explain performance
- provide recommendations
- trigger approved actions

## Analytics Agent

Can:
- analyze business performance
- identify trends
- generate recommendations
