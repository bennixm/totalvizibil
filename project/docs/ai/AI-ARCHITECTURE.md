# AI Architecture

## AI is a Layer

AI should provide intelligence and natural-language interaction.

It should not replace deterministic backend systems.

## Agents

- Company Onboarding Agent
- Website Agent
- Customer Search Agent
- Ads Agent
- Business Account Manager
- Analytics Agent

## Architecture

Voice
↓
Speech-to-text
↓
Conversation Agent
↓
Structured Business State
↓
Specialized Agent
↓
Platform API
↓
Database

## Important

Agents must have limited permissions.

Financial operations should not be controlled directly by an unrestricted language model.
