# AI Cost Control

## Goal

Prevent AI usage from becoming an uncontrolled variable cost.

## Principle

Use AI only where it creates meaningful value.

## Cost Levels

### Level 0 — No AI
Use traditional software.

Examples:
- billing
- tracking
- basic search
- filtering
- validation

### Level 1 — Cheap AI
Examples:
- intent extraction
- classification
- simple content generation

### Level 2 — Advanced AI
Examples:
- complex recommendations
- business analysis

### Level 3 — Expensive Real-Time AI
Examples:
- voice conversation
- video avatar
- real-time interaction

## Pre-Payment Limits

Anonymous / unpaid users must have:
- session limits
- conversation limits
- preview limits
- regeneration limits

## Key Metrics

- AI cost / visitor
- AI cost / prospect
- AI cost / activated business
- AI cost / conversion
- AI cost / search
